# Créditos de terceiros

## Design (tema, glass, animações)

O sistema visual — tema **midnight** (escuro/tech), glassmorphism, botões pill,
brilho ambiente e as animações (`pulse-glow`, `gradient-x`) — foi **portado do**
[Open-AI-UGC](https://github.com/Anil-matcha/Open-AI-UGC), de Anil Matcha,
licenciado sob **MIT**.

Portamos só a **linguagem visual** (tokens de cor, utilitários CSS, DNA dos
componentes). A lógica do produto (pipeline de geração, worker, auth Supabase,
persona congelada, camada de dados) é nossa e não veio de lá.

A licença MIT permite uso e modificação; este arquivo é o aviso de atribuição
que ela pede. O texto da licença original está preservado no histórico do repo
de origem.
